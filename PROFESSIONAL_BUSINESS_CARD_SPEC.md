## 7. Prepress & Industrial Print Production Checklist

Before sending files to Heidelberg / Komori offset presses or digital indigo printers, verify every checkpoint:

- [x] **Finished Trim Boundaries:** Exactly $90.0\text{ mm} \times 50.0\text{ mm}$ ($1.800 : 1$ aspect ratio).
- [x] **Full Bleed Envelope:** $96.0\text{ mm} \times 56.0\text{ mm}$ ($3.0\text{ mm}$ bleed on all 4 borders).
- [x] **Safety Inset:** All live text and emblems maintain $\ge 3.5\text{ mm}$ clearance from the cut margin.
- [x] **QR Code Integrity:** Exact matrix unchanged; encodes `https://q.me-qr.com/esx8n8ll`; $2.0\text{ mm}$ white quiet zone verified.
- [x] **Logo Height Compliance:** Symbol mark sized at $5.0\text{ mm}$; total lockup proportional to 50 mm card.
- [x] **Typographical Height Compliance:** All copy strictly under $5.0\text{ mm}$ (ranging between $1.8\text{ mm}$ and $3.8\text{ mm}$).
- [x] **Vector Outlines:** All fonts (`Poppins`, `Space Grotesk`, `Montserrat`) converted to outlines/curves (`Ctrl+Shift+O` / `Cmd+Shift+O`).
- [x] **Image Resolution:** All rasterized textures and composite graphics rendered at $\ge 300\text{ DPI}$ (or native vector SVG/PDF).
- [x] **Total Ink Limit (TIL / TAC):** Maximum ink density does not exceed $300\%$ on rich black fills.
- [x] **PDF Preset Standard:** Exported as **PDF/X-1a:2001** or **PDF/X-4:2010** with embedded trim and bleed bounding boxes.
