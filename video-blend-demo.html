6 Ways to Merge Video
with Your Environment

⭐ Best
✅ WebM Alpha Channel

Export your video as WebM with VP9 codec + alpha channel. Background is literally transparent — works like a PNG but for video.

<video autoplay loop muted playsinline> <source src="char.webm" type="video/webm"/> </video> /* CSS */ video { filter: drop-shadow(0 20px 40px rgba(124,106,247,.5)); }
🎨 CSS Blend
🧑‍💻
🌟 mix-blend-mode: screen

Video shot on BLACK background. CSS `screen` blend mode removes black pixels, leaving only the character. Works great on dark portfolios!

video { mix-blend-mode: screen; background: transparent; } /* Character pops out of dark bg */ /* Black = invisible */ /* Light = visible ✨ */
🟢 Chroma Key
🎬 Canvas Chroma Key (Green Screen)

Film on GREEN background. JavaScript removes all green pixels in real-time using Canvas API. Industry standard for film & TV.

// Remove green pixels pixels.forEach((r, g, b, a) => { if (g > 100 && g > r*1.4 && g > b*1.4) { a = 0; // transparent! } });
✖️ Multiply
🧑‍💻
✖️ mix-blend-mode: multiply

Video shot on WHITE background. CSS `multiply` removes white pixels. Best for light-themed portfolios or pastel backgrounds.

video { mix-blend-mode: multiply; } /* White bg = invisible */ /* Dark pixels = visible */ /* Best for: light themes */
💎 Glass
🧑‍💻
💎 Glassmorphism Blend

Place character inside a frosted glass container. Background blurs through the glass. Character appears embedded in the scene.

.char-wrap { background: rgba(255,255,255,.08); backdrop-filter: blur(12px); border: 1px solid rgba(255,255,255,.15); border-radius: 24px; }
🌈 Luminosity
🧑‍💻
🌈 mix-blend-mode: luminosity

Character takes on the colors of the background gradient. Creates a surreal, futuristic effect where character absorbs environment colors.

video { mix-blend-mode: luminosity; } /* Character absorbs bg color */ /* Great for colorful portfolios */ /* Very futuristic look ✨ */
// Step-by-Step Guide

How to Create Your
Transparent AI Character

01
Generate AI Video

Use an AI tool to create a realistic talking video of yourself (or a character). Use green screen background for easy removal.

D-ID / HeyGen / SadTalker
02
Remove Background

Remove the green/black background using FFmpeg to export WebM with alpha channel, or use online tools like unscreen.com

FFmpeg / Unscreen.com
03
Convert to WebM

Convert to WebM VP9 format with alpha channel using FFmpeg command for full transparency support in Chrome/Firefox/Edge.

ffmpeg -pix_fmt yuva420p
04
Embed in Portfolio

Place the video in your HTML with autoplay, loop, muted. Apply CSS drop-shadow and position it floating over the dark background.

<video autoplay loop muted>
05
Add AI Chatbot

Connect to OpenAI/Gemini API so visitors can talk to the character. Character responds with text bubbles or voice synthesis.

OpenAI / Gemini API
06
Add Environmental FX

Add glowing orbs, floating particles, ground shadow using CSS. These make the character feel truly embedded in the environment.

CSS Animations + GSAP
// FFmpeg Command — Convert to Transparent WebM
# Step 1: Export frames from AI video (with green screen) ffmpeg -i your_ai_video.mp4 -vf "chromakey=0x00FF00:0.3:0.1" frames/%04d.png # Step 2: Rebuild as transparent WebM ffmpeg -framerate 30 -i frames/%04d.png \ -c:v libvpx-vp9 \ -pix_fmt yuva420p \ -b:v 0 -crf 30 \ character.webm # OR: One-liner from video directly ffmpeg -i input.mp4 -vf "chromakey=black:0.1:0.0" \ -c:v libvpx-vp9 -pix_fmt yuva420p character.webm
