## 🎯 Decision Flowchart

```
START NEW PROJECT
├── Static/Content site?
│   └── Astro → Tailwind CSS → shadcn/ui → Vercel
│
├── Marketing/Landing page?
│   └── Next.js → Tailwind → Framer Motion/GSAP → Vercel
│
├── Web Application (SaaS)?
│   ├── Frontend: Next.js + Tailwind + shadcn/ui
│   ├── Backend: Same server (Next.js API routes) OR NestJS
│   ├── Database: Supabase OR Neon (Postgres) + Prisma
│   ├── Auth: Clerk OR Auth.js
│   ├── State: Zustand + TanStack Query
│   └── Deploy: Vercel + Railway
│
├── E-Commerce?
│   ├── Next.js + Stripe
│   ├── Database: PostgreSQL + Prisma
│   ├── Media: Cloudinary
│   └── Deploy: Vercel
│
└── Creative/Portfolio/3D?
    ├── Next.js OR Astro
    ├── R3F/Three.js OR Spline (no-code)
    ├── GSAP + Framer Motion
    └── Deploy: Vercel
```
